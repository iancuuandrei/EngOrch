## Observed next gap

Running the committed difflib source/test pair through `ri graph` produced
approximately 257 KiB of graph metadata. `ri context` selected one 8 KiB
excerpt per file; later output-contract examples were omitted. Planner
integration therefore needs measured graph bounds and a versioned compiler
that can expose separated symbol/caller/test spans within a fixed total
prompt budget. Raising a bound or adding a CLI command alone is not proof of
better coding outcomes.
