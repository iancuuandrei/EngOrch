# v1.0.4 — Source-bound topology queries

This increment exposes `fabric ri topology` over the existing committed Go
graph. It reports exact observed package dependencies, distinct importer hub
degrees, explicit generator ownership coupling, potentially affected tests and
bounded review groups. Coupled groups retain a common component identity when
split. It does not execute generators, resolve calls, infer source-local import
ownership, authorize writes or produce verification receipts.

The implementation reuses RI facts and graph provenance. Generator closure
uses a finite adjacency walk; package coupling uses a first-selected-file index
instead of repeatedly scanning package files. Review grouping uses linear-size
membership links rather than every file pair. Coverage remains PARTIAL.

Full clean Go qualification and hosted checks remain required before public
main integration. This query capability does not establish isolated writer

benefit. Those roadmap requirements remain active.
