# Atomic numeric generator-coupling fixture

This directory is a design-only topology specification for the pinned
`uber-go/atomic` numeric text task. It does not add an executable row to
`evals/v1/manifest.json` and has no provider or repository effects.

The existing numeric manifest task passed in the separate v1.0.25 Sol High
cohort. That acceptance does not qualify this staged, repeated-cohort
parallel topology. See the [product ledger](../../../../docs/roadmap/v2-product-plan.md)
for the accepted task and remaining topology boundary.

The objective and held-out check are reused unchanged. The desired staged
generator → signed/unsigned leaves topology needs repeated isolated writer
cohorts after confirmed parent integration. The current isolated-writer v1
policy supports only its pristine initial cohort, so the fixture is not ready
to prepare or evaluate until that product seam is implemented and qualified.
